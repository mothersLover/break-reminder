Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [Unreleased]

### Добавлено
- **Кнопка «Подключиться» в напоминании о встрече.** Если во встрече есть ссылка на звонок, рядом с «Понял»
  появляется «Подключиться» — открывает звонок и закрывает окно. Рядом со временем видно сервис (Телемост, Zoom…).
  - Понимает Телемост, Zoom, Microsoft Teams, Google Meet, Контур.Толк, SaluteJazz, МТС Линк, iMCU, Webex,
    VK Звонки и другие; ищет в поле конференции, «Месте», URL и описании встречи.
  - Ссылка неизвестного сервиса берётся только из «Места» или URL; случайные ссылки из описания
    (документы, вики) и ссылки на сам календарь не открываются. Только `http(s)://`.

## [4.0.0] — 2026-10-13

### Исправлено
- **Неверное время встреч из календаря.** Встречи, заведённые в другом часовом поясе (например, по Москве,
  когда на компьютере стоит Новосибирск), показывались по времени «как написано» — без перевода в местное.
  Из-за этого программа ждала конца не той встречи и предлагала перерывы невпопад.
  Теперь время каждой встречи переводится в пояс компьютера по её собственному поясу (`TZID`)
  через системную базу часовых поясов.
- Добавлен тест: разовые и повторяющиеся встречи в чужих поясах дают правильное местное время на любом компьютере.

## [3.0.0] — 2026-10-12

### Добавлено
- **Интеграция с календарём** по секретной iCal-ссылке (Google, Outlook / Microsoft 365, Яндекс, iCloud):
  - во время встречи напоминание о перерыве ждёт и появляется сразу после неё;
  - если перерыв выпадет на встречу — он предлагается до неё;
  - напоминание «через 5 минут встреча»;
  - после длинной серии встреч подряд — большой перерыв;
  - встреча не считается отдыхом, даже если не трогать мышь;
  - ближайшая встреча видна в главном окне.
- Вкладка «Календарь» в настройках с проверкой ссылки.

## [2.0.0] — 2026-10-12

### Добавлено
- **Windows, Linux и macOS.** Программа переписана на Avalonia (.NET 8): общая логика, отдельный слой
  системных функций под каждую ОС.
- Готовые сборки на странице Releases, собираются автоматически при публикации тега.
- Тесты логики рабочего дня и проверка сборки на всех трёх ОС при каждом push.
- Повторный запуск программы показывает уже открытое окно; `--toggle-pause` для горячей клавиши на Linux.

### Изменено
- Первая версия (WinForms, только Windows) перенесена в папку `legacy/`.
  Настройки и история совместимы — новая версия подхватывает их.

## [1.x] — 2026-10-10

Первая версия для Windows (WinForms, .NET Framework 4) — теперь в `legacy/`.

- Рабочий день: «Начать / Закончить», пауза, время работы и отсчёт до перерыва.
- Уведомление в углу, по центру или на весь экран; мигание, звук, «Сделал / Отложить / Пропустить».
- Сон, блокировка и отсутствие за компьютером засчитываются как отдых.
- Большие перерывы, режим «не беспокоить» (созвон, полноэкранные программы), горячая клавиша Ctrl+Alt+P.
- Статистика по неделям, настраиваемые тексты уведомлений.
- Автоматическое начало и конец рабочего дня по расписанию.
