# Что нового

Все заметные изменения проекта. Формат — [Keep a Changelog](https://keepachangelog.com/ru/1.1.0/).

## [5.0.0] — 2026-10-21

### Добавлено
- **ИИ-помощник для хобби, привычек и учёбы** — новая вкладка настроек «ИИ-помощник», выключен по умолчанию.
  - Окно «Помощник» (ссылка на главном экране и пункт в трее): вопросы, проверка домашних заданий и упражнений.
    По умолчанию при проверке сначала подсказка, правильный ответ — после второй попытки (настраивается).
  - **Память между разговорами:** «О себе» (учебник, юнит, цели — пишешь сам) и заметки, которые помощник
    обновляет после каждого разговора: что пройдено, типичные ошибки, договорённости. Их можно посмотреть,
    поправить или стереть («Забыть всё»). «Новый разговор» очищает переписку, но не память.
  - **Подключения:** Claude Code по подписке Claude (без API-ключа), Anthropic API, любой OpenAI-совместимый
    сервис (OpenAI, OpenRouter, DeepSeek, LM Studio…) и локальная Ollama. Кнопка «Проверить подключение».
  - В сервис отправляются только записки помощника и текущий разговор — календарь, задачи и статистика никогда.

### Изменено
- Вкладка настроек «Тексты уведомлений» теперь называется «Тексты» — чтобы все вкладки помещались в одну строку.

## [4.4.0] — 2026-10-15

### Добавлено
- **«Все задачи на сегодня»** — ссылка на главном экране (с числом оставшегося) и пункт в меню трея.
  Открывает единый список по времени: встречи из календаря с местом, описанием и кнопкой «Подключиться»
  и свои задачи. Прошедшие встречи можно скрыть или показать.
- **Свои задачи:** название, заметка и, если нужно, время. Отмечаются «готово» или удаляются;
  невыполненные задачи без времени переносятся на следующий день. Хранятся локально в `tasks.json`.
- **Напоминания о задачах** за N минут (или ровно во время) — с кнопками «Готово» и «Понял».
  Приходят, даже если рабочий день не начат. Задачи на сегодня видны и в утреннем приветствии.

## [4.3.0] — 2026-10-13

### Добавлено
- **Перерыв с подсказками.** В напоминании — «Начать перерыв»: окно превращается в таймер на длительность
  перерыва с упражнениями по шагам (глаза, шея, плечи, спина, запястья, дыхание, вода; на большом — выйти на улицу).
  В конце — мягкий сигнал и «Вернуться к работе»; можно закончить раньше. В главном окне и трее видно,
  сколько осталось. Отключается в настройках — тогда всё как раньше, с кнопкой «Сделал».
- **Отдых для глаз «20-20-20».** Каждые 20 минут (настраивается) в углу на 20 секунд появляется
  «Посмотри вдаль» — без кнопок, само исчезает. Не мешает на встречах, созвонах, в полноэкранных программах
  и перед самым перерывом.
- **Приветствие в начале дня:** погода на сегодня и лучшее время для прогулки, встречи из календаря,
  «главное на сегодня» из вчерашнего отчёта.
- **Отчёт в конце дня** (кнопка «Закончить» или автоконец по расписанию): время работы, перерывы, отдых для глаз,
  встречи, среднее за неделю и поле «Главное на завтра». Если автоконец случился при заблокированном экране —
  отчёт не показывается, итоги просто сохраняются в статистику.
- **Погода** (Open-Meteo, без регистрации): город выбирается в настройках; на большом перерыве подсказывает,
  стоит ли выходить на улицу.
- Новая вкладка настроек «Утро и вечер»; «Не беспокоить» переехало на вкладку «Рабочий день и запуск».

## [4.2.0] — 2026-10-13

### Добавлено
- **Обновление программы.** При запуске (и раз в сутки) программа проверяет новую версию на GitHub
  и предлагает обновиться: окно «Доступна новая версия» с описанием изменений и кнопками
  «Обновить / Позже / Пропустить эту версию».
  - Windows и Linux: программа сама скачивает новую версию, сверяет контрольную сумму SHA-256, заменяет себя
    и перезапускается. Идущий рабочий день не прерывается — продолжается с того же места.
  - macOS: кнопка «Скачать» открывает страницу релиза.
  - Новая вкладка «Обновления» в настройках: текущая версия, «Проверить сейчас», автоматические проверки.
  - Релизы теперь публикуют `SHA256SUMS.txt` с контрольными суммами всех сборок.

> Версии до этой обновляться не умеют — эту версию нужно один раз скачать со страницы релиза вручную,
> дальше обновления будут приходить сами.

## [4.1.0] — 2026-10-13

### Добавлено
- **Кнопка «Подключиться» в напоминании о встрече.** Если во встрече есть ссылка на звонок, рядом с «Понял»
  появляется «Подключиться» — открывает звонок и закрывает окно. Рядом со временем видно сервис (Телемост, Zoom…).
  - Понимает Телемост, Zoom, Microsoft Teams, Google Meet, Контур.Толк, SaluteJazz, МТС Линк, iMCU, Webex,
    VK Звонки и другие; ищет в поле конференции, «Месте», URL и описании встречи.
  - Ссылка неизвестного сервиса берётся только из «Места» или URL; случайные ссылки из описания
    (документы, вики) и ссылки на сам календарь не открываются. Только `http(s)://`.

## [4.0.0] — 2026-10-13

### Исправлено
- **Неверное время встреч из календаря.** Встречи, заведённые в другом часовом поясе (например, по Москве,
  когда на компьютере стоит Новосибирск), показывались по времени «как написано» — без перевода в местное.
  Из-за этого программа ждала конца не той встречи и предлагала перерывы невпопад.
  Теперь время каждой встречи переводится в пояс компьютера по её собственному поясу (`TZID`)
  через системную базу часовых поясов.
- Добавлен тест: разовые и повторяющиеся встречи в чужих поясах дают правильное местное время на любом компьютере.

## [3.0.0] — 2026-10-12

### Добавлено
- **Интеграция с календарём** по секретной iCal-ссылке (Google, Outlook / Microsoft 365, Яндекс, iCloud):
  - во время встречи напоминание о перерыве ждёт и появляется сразу после неё;
  - если перерыв выпадет на встречу — он предлагается до неё;
  - напоминание «через 5 минут встреча»;
  - после длинной серии встреч подряд — большой перерыв;
  - встреча не считается отдыхом, даже если не трогать мышь;
  - ближайшая встреча видна в главном окне.
- Вкладка «Календарь» в настройках с проверкой ссылки.

## [2.0.0] — 2026-10-12

### Добавлено
- **Windows, Linux и macOS.** Программа переписана на Avalonia (.NET 8): общая логика, отдельный слой
  системных функций под каждую ОС.
- Готовые сборки на странице Releases, собираются автоматически при публикации тега.
- Тесты логики рабочего дня и проверка сборки на всех трёх ОС при каждом push.
- Повторный запуск программы показывает уже открытое окно; `--toggle-pause` для горячей клавиши на Linux.

### Изменено
- Первая версия (WinForms, только Windows) перенесена в папку `legacy/`.
  Настройки и история совместимы — новая версия подхватывает их.

## [1.x] — 2026-10-10

Первая версия для Windows (WinForms, .NET Framework 4) — теперь в `legacy/`.

- Рабочий день: «Начать / Закончить», пауза, время работы и отсчёт до перерыва.
- Уведомление в углу, по центру или на весь экран; мигание, звук, «Сделал / Отложить / Пропустить».
- Сон, блокировка и отсутствие за компьютером засчитываются как отдых.
- Большие перерывы, режим «не беспокоить» (созвон, полноэкранные программы), горячая клавиша Ctrl+Alt+P.
- Статистика по неделям, настраиваемые тексты уведомлений.
- Автоматическое начало и конец рабочего дня по расписанию.
