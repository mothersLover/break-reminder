# Отдыхалка (BreakReminder)

Напоминалка о перерывах для Windows. Один `.exe`, ничего устанавливать не нужно.

## Сборка

```
build.bat
```

Используется компилятор C#, встроенный в Windows (.NET Framework 4). На выходе — `BreakReminder.exe`.

## Как работает

- **Начать / Закончить** — рабочий день. Сверху время работы, снизу отсчёт до перерыва.
- **Пауза** — останавливает и время, и отсчёт. Пауза дольше «длительности перерыва» засчитывается как отдых.
- **Уведомление**: «Сделал» (таймер с начала), «Отложить N мин», «Пропустить». Esc = отложить.
- **Сверка с часами**: если компьютер спал / был заблокирован / не было активности мыши и клавиатуры
  дольше длительности перерыва — это засчитывается как отдых, таймер сбрасывается.
- **Большие перерывы**: каждый N-й сделанный перерыв (по умолчанию 4-й) — большой, на 15 мин, фиолетовое окно.
  Отдых дольше большого перерыва (сон, пауза, отошёл) начинает цикл заново.
- **Не беспокоить**: пока занят микрофон/камера (созвон) или открыта полноэкранная программа, напоминание
  ждёт и показывается сразу после. Созвон без движения мышью не засчитывается как отдых.
- **Ctrl+Alt+P** — пауза/продолжить из любой программы.
- **Статистика** — график работы по дням недели, листается неделями.
- Крестик во время рабочего дня сворачивает в трей (цвет значка: серый — не начат, зелёный — работа,
  жёлтый — пауза, красный — пора отдыхать).

**Тексты уведомлений** (заголовки, советы, подписи кнопок) — вкладка «Тексты уведомлений» в настройках.
Советы также лежат в `%APPDATA%\BreakReminder\tips.txt` и `tips_long.txt` (по одному на строку) — их можно
править в Блокноте, файлы перечитываются перед каждым уведомлением.

Настройки: `%APPDATA%\BreakReminder\settings.ini`, история дней: `%APPDATA%\BreakReminder\history.csv`.
